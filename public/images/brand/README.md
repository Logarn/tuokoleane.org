# Tuokoleane brand assets

These transparent assets were prepared from `Tuokoleane initiative Logo new.pdf`, the supplied four-page Adobe Illustrator source.

- `tuokoleane-wordmark-blue.png`: horizontal deep-blue wordmark for light surfaces
- `tuokoleane-wordmark-dark.png`: horizontal near-white wordmark for automatic dark mode
- `tuokoleane-wordmark-white.png`: horizontal pure-white wordmark for fixed dark brand surfaces
- `tuokoleane-symbol-blue.png`: deep-blue symbol for light surfaces
- `tuokoleane-symbol-dark.png`: near-white symbol for automatic dark mode
- `tuokoleane-symbol-white.png`: pure-white symbol for fixed dark brand surfaces

The source artwork uses a deep blue close to `#292f70`. The adaptive dark-mode assets use `#f8f9ff`, while the plain-white exports use `#ffffff`. Do not apply CSS inversion filters to these files.
